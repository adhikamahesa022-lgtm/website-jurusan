MODUL 03 • IDENTITAS

Dharma Satya Jayamahe

Materi mengenai arti, filosofi semboyan kebanggaan Informatika, serta penerapannya dalam berpikir logis.

1. Pengertian Semboyan & Algoritma

Semboyan "Dharma Satya Jayamahe" merupakan identitas dan landasan moral bagi mahasiswa Informatika dalam menjalankan tugas akademis secara terstruktur dan logis, selaras dengan prinsip dasar algoritma.

2. Ciri-Ciri Algoritma & Nilai Utama

  • Memiliki langkah yang jelas dan tidak ambigu.
  • Memiliki tujuan serta kondisi akhir yang terdefinisi.
  • Memiliki proses yang terstruktur dari awal hingga akhir.
  • Menghasilkan keluaran (output) yang tepat dan bermanfaat.

3. Contoh Logika Perhitungan

Contoh sederhana logika algoritma untuk menghitung luas persegi panjang:

  1. Masukkan nilai panjang.
  2. Masukkan nilai lebar.
  3. Kalikan nilai panjang dengan lebar.
  4. Tampilkan hasil perhitungan luas.

4. Contoh Program C++

C++ Code
#include <iostream>
using namespace std;

int main() {
    int panjang, lebar, luas;

    cout << "Masukkan panjang: ";
    cin >> panjang;

    cout << "Masukkan lebar: ";
    cin >> lebar;

    luas = panjang * lebar;

    cout << "Luas = " << luas;

    return 0;
}

5. Kesimpulan

Memahami nilai semboyan dan logika algoritma merupakan fondasi penting bagi mahasiswa Informatika agar mampu menyusun solusi permasalahan secara sistematis sebelum membuat sebuah program.
