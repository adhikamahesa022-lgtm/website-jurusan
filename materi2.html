Sejarah Informatika & HIMATIF

Materi mengenai sejarah berdirinya Informatika UNSIL, pembentukan organisasi HIMATIF, serta konsep dasar algoritma.

1. Pengertian Algoritma

Algoritma adalah langkah-langkah sistematis dan logis yang digunakan untuk menyelesaikan suatu masalah secara terstruktur dan efisien.

2. Ciri-Ciri Algoritma

  • Memiliki langkah yang jelas dan tidak ambigu.
  • Memiliki tujuan serta kondisi akhir yang terdefinisi.
  • Memiliki proses yang terstruktur dari awal hingga akhir.
  • Menghasilkan keluaran (output) yang valid.

3. Contoh Logika Algoritma

Contoh sederhana algoritma untuk menghitung luas persegi panjang:

  1. Masukkan nilai panjang.
  2. Masukkan nilai lebar.
  3. Kalikan nilai panjang dengan lebar.
  4. Tampilkan hasil perhitungan luas.

4. Contoh Program C++

C++ Code
#include <iostream>
using namespace std;

int main() {
    int panjang, lebar, luas;

    cout << "Masukkan panjang: ";
    cin >> panjang;

    cout << "Masukkan lebar: ";
    cin >> lebar;

    luas = panjang * lebar;

    cout << "Luas = " << luas;

    return 0;
}

5. Kesimpulan

Algoritma merupakan dasar penting dalam pemrograman karena membantu programmer menyusun solusi secara terstruktur dan efisien sebelum mengimplementasikannya ke dalam bahasa pemrograman.
